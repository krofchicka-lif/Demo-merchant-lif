# LIF Brand Partner Demo — deploy folder

Static site. No build step.

**Netlify:** drag this `deploy` folder into Netlify, or connect the repo and set
publish directory to `deploy` (leave the build command empty).

**GitHub Pages:** push the contents of this folder to the repo root (or `/docs`)
and enable Pages for that branch/folder.

Entry point: `index.html`. Keep `support.js`, `assets/` and `fonts/` alongside it.
