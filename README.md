# LIF Merchant Demo

Self-contained demo — fonts, images and logic are embedded in `index.html`.

## Deploy

**Fastest (Netlify Drop):** drag this folder onto https://app.netlify.com/drop

**GitHub + Netlify:**
1. Create a new GitHub repo and upload these files to its root.
2. Netlify → Add new site → Import an existing project → GitHub → choose the repo.
3. Build command: leave empty. Publish directory: `.`
4. Deploy.
